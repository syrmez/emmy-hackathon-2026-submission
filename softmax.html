About this replay · caveats and links

One row. 256 random inputs. 128 threads arranged into four warps. Step through immutable snapshots of loads, register updates, shuffle exchanges, shared-memory reductions and output stores.

This is an educational CPU replay of the IR, not a GPU trace or a timing animation. Highlighted threads have parallelizable work; warps and blocks need not execute at the same instant. Arithmetic uses float32 rounding with JavaScript exp, not a bit-exact emulation of PTX’s approximate exponential.

Within-warp exchange map
At a shuffle stage, every lane reads its partner’s old pair before combining. This is not a sequential loop that lets later lanes read earlier lanes’ updated state. There is no shuffle link across a warp boundary.
