A small model. A real compiler.
784 pixels → 128 ReLU features → 10 digits. Float32 throughout.
Compile once. Run on every drawing.
PTX is emitted at server startup; ptxas assembles it on first use and caches the binary. Only input values change between drawings. This is not a stream of newly generated instructions.
Training and the numerical reference use PyTorch. Predictions here use only our compiled GPU kernels.
Timing without the smoke and mirrors.
The live strip shows HTTP kernel submissions and completions, not exact GPU start times. End-to-end latency includes network transfers, queuing and first-use assembly; GPU time is the sum of four single-launch timings, not a benchmark.
